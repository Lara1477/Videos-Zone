# Evidencias del proyecto

Guarda aquí capturas claras en formato PNG. Usa los nombres siguientes para que el README principal pueda mostrarlas fácilmente.

1. `01_login_errores.png` — Inicio de sesión con correo o contraseña inválidos.
2. `02_registro_validaciones.png` — Registro con validaciones visibles.
3. `03_google.png` — Inicio de sesión con Google completado.
4. `04_facebook.png` — Inicio de sesión con Facebook completado.
5. `05_feed.png` — Feed con uno de los seis videos reproduciéndose.
6. `06_pausa_info.png` — Video pausado con canal, miniatura y descripción.
7. `07_perfil_logout.png` — Datos del perfil y botón de cerrar sesión.
8. `08_firebase_usuarios.png` — Firebase Console mostrando los usuarios creados.

Recomendaciones:

- Usa imágenes con buena resolución y recorta elementos innecesarios.
- Evita mostrar claves, contraseñas o datos personales sensibles.
- Comprueba que el nombre del archivo coincida exactamente con la lista anterior.
